# «Кубок Знаний»

Викторина для компании: 2–8 человек играют вместе в одной комнате. Ведущий запускает игру на Android-телефоне, остальные подключаются со своих телефонов по QR-коду или адресу — **приложение ставить не нужно**, всё работает в браузере. Интернет не требуется: достаточно общей Wi-Fi сети. Игру можно вывести на телевизор. Есть одиночный режим «Играть одному» — без сервера и других игроков.

## Что нового в 1.148

- **Тема перед вопросом.** Перед вопросом появляется экран с темой — компания видит, о чём играет. На телевизоре в этот момент видно выбранную тему.
- **Больше способов ответить.** Вопросы с вводом ответа включены по умолчанию, количество подбирается автоматически. Аукцион может закончиться вводом ответа: сначала ставки, потом ответ с клавиатуры.
- **Партия не рассыпается.** Ушёл ведущий — игра встаёт на паузу, после возврата продолжается с того же места. Выйдя из игры, вы больше не попадаете обратно на её экран.
- **Настройка игры собрана по смыслу.** Типы вопросов — в одной карточке, «Очки за ответы» — в отдельном блоке, «Выбор тем игроками» — в своей. Если в раунде выбора темы несколько тем набрали одинаково, ведущий заранее решает, что делать. Настройки сохраняются между запусками.
- **Телевизор стал понятнее.** Под плитками игроков видны имена, в сортировках плашки корзин показывают, сколько ещё осталось разложить. Музыка играет только пока приложение открыто.
- **Обновления.** Приложение само проверяет новые версии и, если установленная слишком старая, просит обновиться и не пускает в игру без обновления. Скачанное обновление не теряется при перезапуске; если файл пропал — приложение скачает его заново само.

## Быстрый старт

1. Установите APK телефона на телефон ведущего (см. «Установка»).
2. Телефон ведущего и телефоны игроков — в одной Wi-Fi сети.
3. Откройте приложение → «Создать игру» → появятся адрес и QR-код.
4. Игроки сканируют QR или открывают адрес в браузере — и входят в игру.
5. Телевизор: откройте ТВ-приложение, оно само найдёт игру в сети.
6. Одиночная игра — «Играть одному» на главном экране.

## Установка

**Телефон.** Скопируйте APK на телефон и откройте его. Android спросит разрешение «Установка неизвестных приложений» — разрешите для того приложения, из которого открываете файл (файловый менеджер, браузер, мессенджер). Без этого разрешения установка не начнётся.

**Обновление.** Ставится поверх старой версии, профиль и настройки сохраняются. Если приложение заблокировало игру и просит обновиться — нажмите «Обновить», дождитесь скачивания и нажмите «Установить». Если кнопка «Установить» не реагирует, приложение подскажет, что не выдано разрешение на установку: «Настройки → Приложения → Специальный доступ → Установка неизвестных приложений → Кубок Знаний → Разрешить».

**Телевизор.** Скопируйте `KubokZnaniy-tv-*.apk` на флешку или передайте на ТВ любым файловым менеджером, затем откройте файл на телевизоре и разрешите установку из этого источника.

## Частые вопросы

**Нужен ли интернет?** Для игры — нет. Нужна общая Wi-Fi сеть: роутер может быть без выхода в интернет. Интернет потребуется только для проверки и скачивания обновлений.

**Игроки не могут подключиться.** Проверьте, что все в одной сети и на роутере выключена «изоляция клиентов» (AP isolation). Адрес и QR-код показывает экран «Создать игру».

**Сколько вопросов?** 23 темы (история, география, наука, кино, музыка, спорт, литература и другие), более 17 000 вопросов и 740 заданий-сортировок. Три уровня сложности.

**Где взять прошлые версии?** В разделе Releases. Приложение обновляется до последней версии автоматически, вручную скачивать старые сборки нужно редко.
